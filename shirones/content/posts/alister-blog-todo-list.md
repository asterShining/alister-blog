搭这个博客最初的想法其实很简单：就是想给自己的生活留一个属于自己的安静角落。可以记日常、聊喜欢的动漫，也可以把折腾技术时踩过的坑和心得顺手存下来。

随着一点点调整，给它换上了 Summer Blue 和 Starry Night 两套主题，搭好了文章体系，把访客浏览统计、点赞和评论区也陆陆续续接通了。不知不觉间，这个站点已经从最初的一个空架子，慢慢长成了一个可以正经用来写字和分享的个人空间。

不过，还有不少想做但还没来得及做的小想法。与其一直堆在脑子里，不如顺手理出一份清爽的清单，记一下现在有什么、还缺什么，方便自己以后慢慢对照着做。

## 功能与规划清单

| 项目 | 状态 | 说明 |
| --- | --- | --- |
| Summer Blue / Starry Night | ✅ 已完成 | Light / Dark 两套主题 |
| 文章系统 | ✅ 已完成 | Markdown / MDX 内容体系 |
| 浏览量 | ✅ 已完成 | 30 分钟匿名访客去重 |
| Like | ✅ 已完成 | 支持点赞和取消 |
| 评论区 | ✅ 已完成 | Turnstile + 基础频控 |
| 友链 | ✅ 已完成 | 已加入第一批友链 |
| About 页面 | 🟩 待完善 | 会继续补充个人介绍 |
| Moments | 🟩 待完善 | 当前功能存在，但内容还没开始整理 |
| Series | 🟩 待完善 | 功能保留，之后有系列文章再启用 |
| 评论管理 | 🟢 计划中 | 后续加入私有审核 / 隐藏 / 删除能力 |
| Admin / CMS | 🟢 计划中 | 私有后台，管理文章和评论 |
| 更多文章 | 🟢 计划中 | 日常、随想、技术、动漫、分享 |
| 动漫 / 追番内容 | 🟢 计划中 | 后续逐渐补充 |
| 站点细节优化 | 🟢 计划中 | UI、移动端、性能继续迭代 |

---

这份清单应该还会不断变化。比起一次性把所有东西全做完，我更希望这个博客能随着自己想写、想记录的东西一点点长出来。

有些功能后面可能会做，有些也可能折腾到最后发现其实没那么必要——都没关系，随性一点就好。

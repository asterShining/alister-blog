# 关于这里

**把喜欢的、想到的，都留在这里。**

这里是 Alister 的个人空间，用来安放日常生活里的想法、最近喜欢的作品，以及动手实践和学习时遇见的点点滴滴。

## 关于我

你好，我是 Alister。

我是一个喜欢折腾新东西的人。平时会接触嵌入式、Linux、机器人以及 Web 等方向的技术，经常会因为对某个细节产生好奇，就从“这是什么”一路探索到“它为什么这样工作”。在做项目的过程中，比起单纯看现成的结论，我更喜欢一边动手一边去理解其中的逻辑。

不过，技术并不是我生活的全部，我也并不打算让这里变成冷冰冰的代码仓库。我也喜欢看动漫、关注有趣的幻想作品，偶尔记录一些日常走走停停时冒出来的随想与碎片。有些尝试最后可能只留下了几行简短的笔记，有些想法可能很微小，但只要觉得有意思、值得记住，我都希望能在这里给它们留一个位置。

## 关于这个博客

这个博客是属于我自己的小天地，基于 Astro 和 Shirone 搭建。

它拥有 Summer Blue（夏日蓝天）与 Starry Night（湖畔星夜）两套视觉主题，适配日间明亮和夜间沉静的阅读氛围。站内现在已经具备了基础的浏览、点赞、评论和友链功能，可以像一个真正的小站一样陪伴我慢慢记录。

它不会一蹴而就，而是一个会随着时间一起长期慢慢完善的小空间。

## 这里会出现什么

这里的内容会大致围绕以下几个方向展开，但不会受限于严格的界限：

- **日常**：生活中的随记、片段与瞬间。
- **随想**：看到某部作品或经历某件事后的想法与杂谈。
- **技术**：折腾嵌入式、Linux、机器人和 Web 开发时的实践与心得。
- **动漫**：喜欢的番剧、角色与长久留存的感动。
- **分享**：偶尔发现的有趣工具、好物或有价值的小灵感。

希望来到这里的你，也能在这里找到一点点舒适或共鸣。
